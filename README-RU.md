# RovoPic AI - Распознаватель качества изображений
Это ИИ, который проверяет качество фотографий на яркость, контрастность и резкость в соответствии со стандартами качества.

Этот мини-проект использует Python OpenCV для распознавания изображений.

Использование RovoPicAI:
склонируйте с помощью git  потом 
1. Выполните команду "pip install -r requierements.txt" в папке проекта
2. Запустите скрипт test.py, и вы сможете использовать RovoPicAI там.


Оценка качества изображения отображается в баллах, где худший балл равен 0,3, а лучший — 3.
